GLPI

Installation et exploration d'un outil de gestion de parc informatique et de ticketing

Qu'est-ce que GLPI ?

GLPI (Gestionnaire Libre de Parc Informatique) est une solution open source de gestion des services informatiques. Il permet aux entreprises de centraliser et d'automatiser la gestion de leur parc informatique, le support utilisateur et la gestion des incidents.

Utilisé par des milliers d'organisations dans le monde, GLPI est un outil incontournable pour les techniciens et administrateurs systèmes.

Open Source ITSM Helpdesk Inventaire IT

Fonctionnalités principales

Gestion des tickets

Création, suivi et résolution des demandes d'assistance avec workflows personnalisables.

Inventaire matériel

Suivi de tout le matériel : ordinateurs, imprimantes, écrans, téléphones, équipements réseau.

Gestion des utilisateurs

Administration des comptes, groupes, profils et entités multi-sociétés.

Tableau de bord

Statistiques en temps réel sur les tickets, le parc et l'activité globale.

Gestion des logiciels

Suivi des licences, versions et déploiements de logiciels dans l'entreprise.

Base de connaissances

Création et partage d'articles techniques et FAQ pour les utilisateurs et techniciens.

Mon installation

Déploiement sur environnement WAMP

Dans le cadre de ma formation BTS SIO, j'ai installé et configuré GLPI 11 sur un environnement de développement local WAMP (Windows, Apache, MySQL, PHP).

Étapes réalisées :

• Téléchargement et installation de GLPI 10 sur le serveur Apache local

• Configuration d'un alias Apache pour rediriger vers le dossier /public

• Création de la base de données MySQL via phpMyAdmin

• Initialisation des tables via la console GLPI (php bin/console database:install)

• Configuration du module mod_rewrite d'Apache pour la réécriture d'URL

• Connexion en tant que Super-Admin pour explorer les fonctionnalités

PHP 8.3 MySQL Apache 2.4 GLPI 11

Compétences acquises

Cette mise en pratique m'a permis de :

• Comprendre l'intérêt d'un outil ITSM en entreprise

• Maîtriser l'installation d'une application web sur serveur local

• Configurer un serveur Apache (alias, mod_rewrite, AllowOverride)

• Utiliser les commandes en ligne pour administrer une application PHP

• Manipuler une base de données MySQL via phpMyAdmin

• Diagnostiquer et résoudre des erreurs de configuration serveur
